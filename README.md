# alan-pi-skills

Pi skills for web search and webpage fetching via Puppeteer with a persistent Chrome instance.

## Skills

- **google-search** — Perform Google searches via Puppeteer
- **get-webpage** — Fetch and extract readable content from any URL

## Install

```bash
pi install https://github.com/tikikun/alan-pi-skills
```

## Usage

Once installed, the skills are automatically available in pi. The agent will load them on-demand when your task matches their description.

You can also invoke them directly:

```bash
/skill:google-search <query>
/skill:get-webpage <url>
```
